## Model name matching

The full model name can appear within a longer custom name: `My Crystal Trident of Power +1` selects Crystal Trident. Prefixes, suffixes, styled text components (color, bold, italic, custom font), and legacy section-sign formatting codes are supported. The model-name words must remain intact; formatting codes may be inserted between letters. Longer overlapping model names take precedence. Capitalization is ignored except historical aliases that distinguish different models solely by case. Unnamed items retain their normal models, and item eligibility is unchanged. RP Renames continues to show clean canonical names.

Spear GUI compatibility: addon 1.3.2 preserves named models in inventory and RP Renames previews when the spear mods request the inventory model. Ordinary spears retain their default icons.
