Apocalypse Mace Visuals 1.0.1 is a small client-only addon registering the native item property apocalypse_mace_visuals:enchantment_variant exclusively on Items.MACE. It uses the installed game's enchantment component and keyed registry holders, retaining arbitrary extra enchantments. This bridges the source pack's OptiFine enchantment conditions without adding OptiFine/CIT Resewn or modifying Polytone. Source/build: scripts/mace_visuals/. Build using build.py --output NEW_EXTERNAL_DIRECTORY --better-combat mods/bettercombat-neoforge-2.4.0+1.21.1.jar (the existing pinned compiler classpath; Better Combat is not a runtime dependency of this visual addon).

Validation: 700 isolated native dedicated-server assertions passed, including 28 additional model-selector checks covering every normal Breach/Wind Burst level, extra enchantments, both-enchantment precedence, Density, renamed stacks, and rejection of swords/axes/tridents carrying the same enchantments. The client entrypoint is restricted to Dist.CLIENT. These checks validate selection logic and prior combat scope, not client model baking/rendering or Polytone precedence in gameplay. Client checks pending: base mace, Breach I/IV, Wind Burst I/III, both enchantments, enchanted Zephyr, inventory/first/third-person, Better Combat slam, and wrong-item renames in RP Renames.
