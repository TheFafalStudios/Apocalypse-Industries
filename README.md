# Apocalypse Industries

## Install with ATLauncher

**[Download the pack](https://github.com/TheFafalStudios/Apocalypse-Industries/releases/latest/download/Apocalypse-Industries-ATLauncher.zip)** · **[Read the changelog](CHANGELOG.md)**

You only need ATLauncher, a Minecraft: Java Edition account, and the download above. The installer gets the pack files for you.

1. **Install ATLauncher.** Download it from [atlauncher.com](https://atlauncher.com/downloads), open it, and sign in with your Minecraft account.
2. **Download the pack.** Click **Download the pack** above. Save `Apocalypse-Industries-ATLauncher.zip` somewhere easy to find, such as Downloads. **Keep it zipped.**
3. **Import it.** In ATLauncher, open the **Instances** tab and click **Import**. Select the ZIP you downloaded, then click **Import**.
4. **Install the instance.** Keep the name **Apocalypse Industries**, or choose your own, then click **Install**. An instance is a separate copy of Minecraft for this pack.
5. **Launch the pack.** Find Apocalypse Industries in **Instances** and click **Play**. Allow the installer to download the required files. The first launch can take longer while everything is set up.
6. **Start playing.** When the Minecraft menu appears, choose **Singleplayer**, or use **Multiplayer** with the server address provided by your server host.

> Use the pack download linked above. GitHub's **Code → Download ZIP** and **Source code** downloads are repository files, not the ATLauncher installer.

Need help with the import screen? See [ATLauncher's illustrated import guide](https://wiki.atlauncher.com/guides/importing-an-instance/).

## Keeping the pack updated

Launch the same instance from ATLauncher. It checks for pack updates before Minecraft starts, so you do not need to download and import the ZIP again for routine updates. Let any update downloads finish before playing.

For multiplayer, your server must use a matching pack version. If an update prevents you from joining, check with your server host.
