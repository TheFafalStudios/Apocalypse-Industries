# Apocalypse Industries

Version-controlled source for the live Apocalypse Industries Minecraft modpack.

- Minecraft: 1.21.1
- Loader: NeoForge 21.1.248
- Launcher: ATLauncher
- Baseline ancestry: CurseForge `Apocalypse Industries 1.0.2` (file `8380248`)

The live ATLauncher instance is the development source of truth. This repository stores Packwiz download references plus pack-owned configuration, KubeJS scripts, and datapacks. It does not redistribute third-party mod JARs, player worlds, logs, launcher state, or credentials.

See [docs/RELEASING.md](docs/RELEASING.md) for the intended update and release workflow.
